==========================================================================
          LEVEL 2: WEIGHTS, RARITY & MODULES (Scarcity & Style)
==========================================================================

GOAL: Control the feel of your world, simulate scarcity, and customize
what the engine displays.

In Level 1, every item had an equal chance. In Level 2, we use weighted
probability so a "Sharpened Rebar" can roll 80% of the time while a
"Pre-War Plasma Cutter" rolls 5% of the time.

--------------------------------------------------------------------------
[ 1. FROM STRINGS TO OBJECTS ]
--------------------------------------------------------------------------

Instead of a plain word like "Sword", wrap an option in curly braces { }
to give the engine extra properties:

  - Value:  The text of the item or name.
  - Weight: How likely it is to roll (defaults to 1 if omitted).
            Setting Weight to 0 disables an option temporarily (the
            Pre-Flight Validator will flag it as a reminder).
  - Rarity: Optional badge label (Common, Uncommon, Rare, Epic, etc.).

You can freely mix plain strings and objects inside the same list. Any
plain string is automatically treated as Weight 1 with no rarity badge.

--------------------------------------------------------------------------
[ 2. UNDERSTANDING WEIGHTS ]
--------------------------------------------------------------------------

Think of weights like raffle tickets. If a Rusty Pipe has 80 tickets and
a Plasma Cutter has 5 tickets, all tickets go into one hat. Weights do
not need to add up to 100 -- the engine calculates the exact ratio for
you automatically.

  - High Weight (50-100): Everyday gear, common backgrounds.
  - Mid Weight  (15-30):  Uncommon finds, specialized equipment.
  - Low Weight  (1-5):    Rare treasures, mythic relics.

--------------------------------------------------------------------------
[ 3. COLOR-CODED RARITY ]
--------------------------------------------------------------------------

When "ShowRarity": true is set in Modules, the engine prints color-coded
rarity badges next to rolled traits (without polluting narrative bios):

  - Common                      -> Gray
  - Uncommon                    -> Green
  - Rare                        -> Cyan
  - Epic                        -> Magenta
  - Legendary / Mythic / Unique -> Yellow
  - Any custom label            -> White

--------------------------------------------------------------------------
[ 4. PROBABILITY: NICKNAMES, GENDER & OPTIONAL TRAITS ]
--------------------------------------------------------------------------

Level 2 also unlocks three probability tools inside any archetype:

  - NicknameChance: A decimal from 0.0 (never) to 1.0 (always).
  - GenderOdds:     A weighted dictionary (e.g., {"Male": 45, "Female":
                    45, "Non-Binary": 10}). Requires UseGender: true.
  - OptionalTraits: Trait categories that only roll if they pass a
                    Chance check (0.0 to 1.0). If the check fails, the
                    trait is cleanly omitted from the character sheet.

--------------------------------------------------------------------------
[ 5. ALL 8 MODULE TOGGLES ]
--------------------------------------------------------------------------

Every flag in "Modules" defaults to true if omitted. Turn flags off to
reshape the engine for non-game genres (such as novel character sheets):

  - ShowRarity:     Display color-coded [Rarity] badges.
  - UseNarrative:   Generate biographies from BioTemplates.
  - UsePointPools:  Roll RPG/psychological stat pools.
  - ShowStatBars:   Draw visual [█████░░░░░] bars next to PointPools.
  - UseGender:      Roll GenderOdds and display the GENDER line.
  - ShowTags:       Display the active [TAGS] line on the sheet.
  - UseRanges:      Roll independent numeric Ranges (Age, Bounty, etc.).
  - UseMultiTraits: Roll multi-pick lists (inventories, quirks, tells).

--------------------------------------------------------------------------
[ LEVEL 2 EXAMPLE FILE (Copy-Paste Ready) ]
--------------------------------------------------------------------------

{
  "UniverseName": "Loot Hunter Alpha",
  "ArchetypeTitle": "Scavenger",
  "Modules": {
    "ShowRarity": true,
    "UseNarrative": false,
    "UseGender": true,
    "ShowTags": false
  },
  "Archetypes": {
    "Wastelander": {
      "NicknameChance": 0.6,
      "GenderOdds": {
        "Male": 45,
        "Female": 45,
        "Non-Binary": 10
      },
      "FirstNames": ["Dusty", "Cinder", "Jax", "Mara", "Kestrel"],
      "LastNames": ["Scrap", "Ash", "Voss", "Flint", "Mercer"],
      "Nicknames": ["Rust-Hand", "Crow", "Sparks", "Two-Shot"],
      "MandatoryTraits": {
        "Starting Weapon": [
          { "Value": "Sharpened Rebar", "Weight": 70, "Rarity": "Common" },
          { "Value": "Sawed-Off Pipe Gun", "Weight": 20, "Rarity": "Uncommon" },
          { "Value": "Old Service Revolver", "Weight": 12, "Rarity": "Rare" },
          { "Value": "Pre-War Plasma Cutter", "Weight": 4, "Rarity": "Epic" },
          { "Value": "Prototype Rail Carbine", "Weight": 1, "Rarity": "Legendary" }
        ]
      },
      "OptionalTraits": {
        "Lucky Find": {
          "Chance": 0.4,
          "Options": [
            { "Value": "Cracked Geiger Counter", "Weight": 50, "Rarity": "Common" },
            { "Value": "Sealed Military Ration", "Weight": 30, "Rarity": "Uncommon" },
            { "Value": "Working Solar Battery", "Weight": 10, "Rarity": "Rare" }
          ]
        }
      }
    }
  }
}

--------------------------------------------------------------------------
[ PRO TIP ]
--------------------------------------------------------------------------

If you are making a non-RPG universe (like a novel cast or historical
roster), set "ShowRarity": false. You can still use "Weight" to make
certain traits rare without printing video-game loot labels on the sheet.
